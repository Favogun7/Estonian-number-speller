# Estonian-number-speller
Python command-line program that converts integers into Estonian number words.
## Features

- Converts integers from 0 to 999,999 into Estonian words
- Uses recursion and modular arithmetic
- Reads numbers from an input file
- Writes formatted results to an output file
- Validates the requested language code

## Usage

```bash
python spell_numbers.py est numbers.txt number_words.txt
